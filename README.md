Car Evaluation System

Internship: CODETECH
Author: Shaik Rehaman

Project Description

Car Evaluation System is a Machine Learning project that predicts the acceptability of a car based on its features, such as buying price, maintenance cost, number of doors, passenger capacity, luggage boot size, and safety.

Objectives

- Analyze car evaluation data.
- Clean and prepare the dataset.
- Train Machine Learning classification models.
- Compare model performance.
- Predict car acceptability.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib

Machine Learning Algorithms

- Decision Tree Classifier
- Random Forest Classifier

Dataset

UCI Car Evaluation Dataset.

Project Files

- "Car_Evaluation_System.ipynb" – Main project notebook.
- "requirements.txt" – Required Python libraries.
- "Task_4_Car_Evaluation_Results.zip" – Model and output files.
- "Task_4_Documentation.zip" – Project documentation.

How to Run

1. Open the notebook in Google Colab.
2. Install the required libraries.
3. Run all notebook cells.
4. View the model comparison and prediction results.

Expected Output

- Cleaned car evaluation dataset.
- Model accuracy comparison.
- Classification report.
- Confusion matrix.
- Sample car acceptability prediction.

Conclusion

This project demonstrates how Machine Learning classification algorithms can predict car acceptability using vehicle features.
