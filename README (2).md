# Car Evaluation System

**Author:** Shaik Rehaman

## Project Description
This Machine Learning project predicts car acceptability
based on vehicle features.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Joblib

## Machine Learning Algorithms
- Decision Tree Classifier
- Random Forest Classifier

## Dataset
UCI Car Evaluation Dataset

## Project Output
The system predicts whether a car is:
- Unacceptable
- Acceptable
- Good
- Very Good
